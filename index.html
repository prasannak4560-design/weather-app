API Configuration & Security

🔒 Production Security Best Practice:

In client-side single page apps, storing API keys in JavaScript or LocalStorage exposes them to inspection in DevTools. For production deployments, always route weather API calls through a secure backend proxy or serverless function (e.g. Next.js API route, Cloudflare Worker, or Express) where your secret key is securely held in an environment variable (`.env`). Refer to API_SECURITY_GUIDE.md for copy-paste backend templates.
